# ShoeSync LDSM405

ShoeSync es una aplicación web orientada a la gestión y seguimiento
de procesos de producción de calzado.

## Objetivo

Facilitar el registro, seguimiento y consulta de pedidos mediante
códigos QR.

## Usuarios

- Cliente
- Productor
- Empleado
- Administrador

## Tecnologías

- HTML/CSS/JavaScript
- API REST
- MySQL
- Git
- GitHub
