# ShoeSync - Plataforma Web para la Industria del Calzado

## Descripción del Proyecto
ShoeSync es una aplicación web frontend completa diseñada para centralizar, controlar y monitorear todos los procesos de fabricación, ventas, pedidos, inventario y seguimiento mediante códigos QR en empresas de calzado.

## Estructura Técnica
- **HTML5:** Marcado semántico y limpio.
- **CSS3:** Hoja de estilos compartidos, componentes y diseño responsivo adaptativo (Mobile First & Desktop).
- **JavaScript Vanilla:** Autenticación simulada, manipulaciones DOM y almacenamiento local (`localStorage`).
- **Bootstrap 5 & Bootstrap Icons:** Estructura de rejilla, modales, alertas e iconografía profesional.
